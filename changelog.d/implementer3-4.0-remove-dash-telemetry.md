- **4.0: `hv dash` and `hv telemetry` are removed (#433).** Both exit 2 with one line naming the module command that replaced them (`hdash dash`, `hwatch telemetry`), whatever arguments follow, and run nothing. The session hook (`session_hook.sh`), the MCP `hive_telemetry` tool and the Hermes plugin record through the hwatch module directly and stay silent without it; `hive_telemetry_report` returns the pointer as its text. CLI_REFERENCE, CONTRACT_HISTORY (a 4.0 entry; `CONTRACT_VERSION` unchanged until the contract bump), and every doc that told a reader to run the removed verbs are updated.
