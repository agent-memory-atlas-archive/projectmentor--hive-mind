- **Module doctor slot (3.1, #294 PR 4).** `hv doctor` runs a contract-1 module's own `doctor` (an argv, no shell; 20 s, 64 KiB, 100 results, 400 characters a string, narrow environment with `HIVE_DOCTOR_MODE`) for a module signed by its pinned publisher, merges the results into `modules:<name>` (a timeout, crash or malformed answer is a warn; a reported fail is a fail), caches them in `$HIVE_HOME/.module-doctor/<name>.json`, and also runs at the end of `module add`/`update` (`--require-healthy` exits 1 on a fail) and from the doctor timer (`HIVE_DOCTOR_MODE=timer`). A declared runtime missing from the module's PATH is a core warn. `hv doctor --fix` never runs module code.
