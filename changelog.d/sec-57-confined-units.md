- **Security: `confined` module units are now sandboxed (#57).** A module whose effective trust tier is `confined` (signed so, or lowered with `hive-mind module trust <name> confined`) runs with `ProtectSystem=strict`, `ProtectHome=tmpfs` (its own key directory bound read-write, its directory and runtime `PATH` entries read-only), `PrivateTmp=yes`, `NoNewPrivileges=yes` and an empty `CapabilityBoundingSet=`. `module trust` now re-renders and restarts the unit, and `doctor` compares units against the effective tier and the recorded `PATH`. A `trusted` unit is byte-for-byte unchanged.
