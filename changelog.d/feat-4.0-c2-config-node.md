- **`config node`, `module list --json`, `module config <name> schema`, and `--non-interactive` (4.0, hconfig C2).** `hv config node list|get|set <key> [value] [--json]` reads and writes the node-local keys of `.peers.json` (`port`, `bind`, `sync_auth`, `sync_auth_outbound`, `dashboard_viewers`, `dashboard_viewer_port`) with the writer `hv sync auth` now shares (every other key is kept; an env override shows as `source: env`, masked). `hive-mind module list --json` prints the list-table columns as JSON; `hive-mind module config <name> schema` prints the installed manifest's `config_schema`. `hive-mind config set` and `hive-mind module config <name> set --fleet|--fleet-node` take `--non-interactive`: no passphrase prompt and no read of stdin, exit 5 (nothing signed) when the unlock agent is absent, locked or refuses the act.
