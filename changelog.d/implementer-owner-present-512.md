- `hive-mind owner present` and `hive-mind owner member` (#512): read one JSON request on stdin (`{tickets, assertion}` or `{kind, record, assertions}`), forward it to the gated agent's `present` or `member` op and print the agent's reply as JSON (exit 0 ok, 1 refused or no agent, 2 bad request). They never prompt or read a terminal. For modules such as the approval module that reach core only through the CLI.
