- **`dashboard_share` node key (4.0, hdash P4).** `hive-mind config node set dashboard_share true|false` joins `dashboard_viewers` and `dashboard_viewer_port` as the operator-only, node-local switch for hdash's read-only tailnet viewer listener. It is a `NODE_KEYS` row (never a `set-config`, never journaled), defaults to off, and the core daemon gains no listener and no code for it; hdash reads it at start.
