- **`hive-mind config schema --json` and `config show --json` (4.0, hconfig C1).** `schema` prints the two key tables, governed (`GOVERNED_KEYS`, now the only table `config set` consults for membership, type, choices and range) and node-local (`NODE_KEYS`, never a `set-config`); `show` prints each governed key's value, source and `set_by` (`device_id`, `ts`, `sid` of its last honoured `set-config`) and an operator-only `governance` block. **Behaviour change:** every refusal of `hive-mind config set` (unknown key, bad value, out-of-range value, an `x-` value too long, no owner key, the #122 guard) now exits 1 instead of 0; the success path's output and code are unchanged. A value of NaN for a ranged key is now refused.
